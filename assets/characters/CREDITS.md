# Character assets

All files here are CC0 1.0 (public domain dedication, https://creativecommons.org/publicdomain/zero/1.0/).
The meshes were trimmed for the game (textures removed, decimated to ~4k triangles with UVs kept, rebuilt as GLB);
every texture the characters wear is painted at runtime by `src/models/charkit.js`, `professor.js` and `creatures.js`.
