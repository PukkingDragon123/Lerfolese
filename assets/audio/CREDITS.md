# Audio credits

All game sound is 8-bit / chiptune from free, licence-checked packs. Nothing was synthesised for this project. Edits were limited to trimming silence, short fades, loudness normalisation and MP3 encoding.

Licences: every SFX and music file below is **CC0 1.0** (public domain dedication; checked on each source page and in the licence / INFO file inside each pack). Ambience loops keep their earlier, separately vetted sources (CC0, public domain, CC BY), listed at the end.

## Processing

- **SFX** (`sfx/`): mono, 44.1 kHz, MP3 CBR 112 kbps. Silence trimmed, 2.5 ms fade-in and up to 20 ms fade-out, the loudest 400 ms window normalised to about -18 dBFS RMS, peaks limited to -1 dBFS. `vol` in `manifest.json` keeps the category balance (UI soft, cards moderate, hits and roars prominent).
- **Music** (`music/`): stereo, 44.1 kHz, MP3 LAME VBR V6, loudness-normalised (EBU R128, about -18 LUFS integrated, true peak -1.5 dBTP). The stings (`music/sting_*.mp3`, also in `sfx/` as `sting_*`) are processed like SFX.
- **Ambience** (`amb/`): stereo, 44.1 kHz, MP3 CBR 112 kbps. Loops are 45-60 s. Layers are levelled before mixing. The tail is crossfaded into the head (3 s, equal-power), so the file loops seamlessly. Loudness is about -24 LUFS integrated. `night` (-25) and `campfire` (-26) are slightly lower because of peak limiting, and their `vol` is raised to match. MP3 adds about 1105 samples of encoder delay at the start, so for sample-accurate looping in Web Audio, set `loopStart` to about 0.025 s.
